# 배관 누수 감지 학습 코드

Google Colab에서 실행하는 ResNet18 전이학습 코드입니다.
Colab 노트북에서 직접 다운로드(.ipynb)하여 이 폴더에 함께 업로드하세요.

## 데이터 구조
```
사진/
├── 정상 사진/  (264장)
└── 불량 사진/  (261장)
```

## 핵심 방법론
- ResNet18 기반 전이학습, 정상/불량 2클래스 분류
- 흡습지 색상 변화(젖음)를 통한 누수 판별
- 촬영 세션 단위 시간순 분할로 검증
- 단일 촬영 각도·고정 배경 조건에서 높은 수준의 판별 성능 확인
- 다양한 촬영 조건에서의 추가 검증은 후속 과제
