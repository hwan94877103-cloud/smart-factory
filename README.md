# 스마트팩토리 온도 모니터링 및 이상 감지 시스템

스마트팩토리 공정 라인을 축소 모형으로 구현하여, 다중 온도 데이터 수집과 열전소자(펠티어) 기반 온도 제어, 시각 정보 기반 이상 감지를 통합한 프로젝트입니다.

```
[노트북 — 중앙 제어 및 데이터 분석]
      │
      ├── 아두이노 1 : 온도센서 7채널 측정
      ├── 아두이노 2 : 수중펌프 유량 제어
      ├── ESP32      : 펠티어 6채널 발열 제어
      ├── 열화상카메라 : 펠티어 소자 발열 상태 촬영
      └── 라즈베이파이 카메라 : 배관 연결부 누수 상태 촬영
```

---

## 시스템 구성

### 1. 온도 측정
- DS18B20 방수형 온도센서 7개(기준 1 + 공정구간 6)
- 1-Wire 통신, 3그룹 분산 배치, 4.7kΩ 풀업저항
- 센서 고유 주소 기반 식별로 배선 재구성과 무관한 데이터 정합성 확보

### 2. 유량 제어
- L298N 모터드라이버 + 다이아프램 수중펌프(6~12V)
- PWM(0~255) 속도 제어, 12V 어댑터 구동

### 3. 냉/발열 제어
- ESP32 + MOSFET 6채널 PWM 제어(20kHz)
- 채널별 이중 퓨즈(전원단/부하단, 8~10A) 보호 구조
- 방열용 DC 5V 팬 상시 구동

### 4. 통합 데이터 수집
- 온도 데이터 수신을 트리거로 ESP32 상태를 즉시 조회하는 요청-응답 구조
- 6채널 × 4단계(0~3) 완전요인설계, 4,096개 조합 × 3회 반복 측정
- 총 12,288행의 실측 데이터 확보

---

## 데이터 분석

- 결측치·이상치 처리 후 12,089행(4,070개 조합, 99.37%) 확보
- 세기(Digit_Sum)-온도변화(Delta_T) 회귀분석: **R² = 0.8928**
- 잔차 기반 품질 판정 기준 수립: 양품 90.04% / 불량 9.96%
- 머신러닝 분류 모델(Gradient Boosting): **Accuracy 95.66%**

## 시각 기반 이상 감지

| 대상 | 방법 | 결과 |
|---|---|---|
| 펠티어 소자 과열 | 열화상카메라 + ResNet18 전이학습(5단계) | **93.95%** |
| 배관 연결부 누수 | 카메라 + ResNet18 전이학습(2클래스) | 높은 수준의 판별 성능 확인 (다양한 촬영 조건 검증은 후속 과제) |
