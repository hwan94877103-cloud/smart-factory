# 열화상카메라 과열 감지 학습 코드

Google Colab에서 실행하는 ResNet18 전이학습 코드입니다.
`thermal_camera_training.ipynb` 참고.

## 데이터 구조
```
열화상/
├── 정상 열화상/
│   ├── 정상 0단계/
│   ├── 정상 1단계/
│   └── 정상 2단계/
└── 불량 열화상/
    ├── 불량 3단계/
    └── 불량 4단계/
```

## 핵심 방법론
- ResNet18 기반 전이학습
- 5단계(정상 0~2, 과열 3~4) 분류 후 2진 매핑
- 촬영 세션(폴더) 단위 시간순 분할로 데이터 누수 방지
- 5단계 세부 분류 검증 정확도: **93.95%**
